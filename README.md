# Coupon
大四畢業專題<br/>
開發Android，手機優惠券App作品 (七人合作)<br/>
作品網址：https://lightningpi.website/app_php/app <br/>
<br/>
系統建置規格：<br/>
PHP、Phonegap手機程式開發框架、jQuery Mobile、<br/>
JavaScript、Ajax、JSONP、<br/>
HTML5、CSS3、MySQL<br/>
<br/>
系統主要功能：<br/>
今天吃什麼(隨機產生一筆優惠券)<br/>
商家列表、商家內容(商家長期優惠、分時優惠)、<br/>
收藏商家功能、已收藏商家列表、<br/>
聯絡商家(手機打電話功能，已輸入店家聯絡號碼)、<br/>
商家位置(顯示商家地址)<br/>
<br/>
我要優惠券(優惠券列表)、優惠券內容、<br/>
收藏優惠券、集券冊(已收藏優惠券)<br/>
會員註冊、登入、登出<br/>
<br/>
聯絡我們(回報商家或優惠問題)<br/>
問題回報(回報App問題、其他建議)<br/>
<br/>
<br/>
手機檔案位置：所有檔案，(不包括app_php資料夾)<br/>
<br/>
伺服器檔案位置：app_php資料夾內，所有檔案<br/>
<br/>
<br/>
由於PhoneGap官方網站已關閉<br/>
(PhoneGap不再提供服務)<br/>
將大四專題舊有的Android手機程式碼內容<br/>
修改成新架設的伺服器IP後<br/>
發現Android apk均無法順利運作<br/>
無法以手機程式方式呈現<br/>
<br/>
基於PhoneGap跨平台特性<br/>
原本在Android使用的相同程式碼<br/>
也可以透過網頁方式運作呈現<br/>
故改以線上網頁方式，呈現手機程式的功能<br/>
