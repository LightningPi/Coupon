# Coupon
大四畢業專題<br/>
開發 Android，手機優惠券App作品(PHP)(七人合作)<br/>
手機檔案位置：所有檔案，(不包括app_php資料夾)<br/>
伺服器檔案位置：app_php資料夾<br/>
資料庫檔案：coupon.sql <br/>
<br/>
一、系統建置規格：<br/>
PHP、Phonegap手機程式開發框架、jQuery Mobile、<br/>
JavaScript、Ajax、JSONP、<br/>
HTML5、CSS3、MySQL<br/>
<br/>
二、系統主要功能：<br/>
1.今天吃什麼(隨機產生一筆優惠券)<br/>
2.商家列表、商家內容(商家長期優惠、分時優惠)<br/>
(1)收藏商家功能<br/>
(2)已收藏商家列表<br/>
(3)聯絡商家(手機打電話功能，已輸入店家聯絡號碼)<br/>
(4)商家位置(顯示商家地址)<br/>
(5)聯絡我們(回報商家或優惠券問題)<br/>
<br/>
3.我要優惠券(優惠券列表)、優惠券內容、收藏優惠券功能<br/>
4.集券冊(已收藏優惠券列表)<br/>
5.會員註冊、登入、登出<br/>
6.問題回報(回報App問題、其他建議)<br/>
